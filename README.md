# Tortas El Gato

Página web de una pastelería dedicada a mostrar postres caseros y facilitar la elección de un antojo.

## Descripción

La página presenta una identidad visual cálida con fondo crema, colores coral, amarillo y verde, además de una tipografía expresiva. El encabezado incluye el logo de Tortas El Gato y una navegación sencilla.

## Secciones principales

- **Inicio:** bienvenida a los visitantes y presentación de la pastelería.
- **Galería de postres:** tarjetas con nombre, descripción, precio e imagen de cada postre.
- **Filtros:** opciones para ver todos los postres, tortas o postres individuales.
- **Selección:** cada tarjeta puede marcarse como elegida y muestra un contador de postres seleccionados.
- **Nuestra historia:** breve presentación de la identidad y los valores de la pastelería.
- **Contáctanos:** horarios, dirección y correo electrónico.

## Diseño responsive

La página está adaptada para computadores, tabletas y celulares. En pantallas pequeñas se reorganizan el encabezado, los botones, la galería y la información del pie de página para facilitar la lectura y la navegación.
